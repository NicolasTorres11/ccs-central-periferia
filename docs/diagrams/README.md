# Diagramas

Esta carpeta contiene artefactos listos para importar en herramientas de diagramacion.

## Modelo ER
- `../../database/model/ccs-er-model.dbml`: modelo DBML oficial para [https://dbdiagram.io/](https://dbdiagram.io/d/er-model-ccs-periferia-6a04ab4854a51d93d31d2b04).
- `er-model.mmd`: version auxiliar en Mermaid, util solo si se requiere otro formato de visualizacion.

El modelo fuente esta documentado en `../er-model.md`.
